## SITE secondary-subset discrepancy (47.3 vs 48.3) — DOCUMENTED, not resolved

Two committed artifact paths disagree on the secondary (orientation-keyword) subset:

- Run-time metrics JSON `results/site/zeroshot_image_metrics.json` and the
  canonical table `results/tables/site_validation_table.md`: n = 1,824, raw 47.3%, CAA 22.6%.
- Row-level `results/site/zeroshot_7b_predictions.csv` (2,024 rows tagged
  `secondary`, consistent with the frozen protocol's 2,024 image IDs): raw 48.32%, CAA 23.96%.

All other SITE numbers (all-images 54.2/31.1, primary 75.1/59.2, modalities,
per-source) are **bit-identical** between the two paths (verified by
recomputation). **Decision:** the main paper reports the canonical values
(1,824; 47.3; 22.6) — matching the experimenter's frozen table — and documents
the CSV+protocol recomputation in a footnote (main text) and App. E. Both values
support the same conclusion (orientation ≪ primary).
