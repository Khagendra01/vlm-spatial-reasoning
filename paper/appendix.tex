\subsection{SITE Protocol Notes}
The SITE image evaluation uses the frozen configuration hash \texttt{28f4cc09887477af}. The protocol uses Qwen2-VL-7B-Instruct, the benchmark's native multiple-choice prompt and parser, greedy decoding, and a 16-token generation ceiling. The 16-token ceiling was validated against the first 125 examples after an earlier 128-token ceiling and did not change parsed answers. The image-only external validation comprises 1,368 single-image and 1,223 multi-image examples.
