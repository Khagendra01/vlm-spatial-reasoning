\section{Frozen Metric Definitions}
From the committed analyzer (\texttt{analyze\_tier\_c.py}), read as the
authoritative definitions:
\begin{itemize}[leftmargin=*]
  \item $A_{\text{transform}}(m) = P(\text{transformed prediction} =
        \text{expected transformed label})$: transformed-answer accuracy.
  \item $C_{\text{pair}}(m) = P(\text{pair consistency})$: the model's two
        answers on the same example obey the linked-answer law.
        hflip\_flip: $P(\text{mirrored} \neq \text{normal})$ (answer-update
        rate); hflip\_invariant: $P(\text{mirrored} = \text{normal})$
        (response-stability rate); relcomp/facingcomp: flip-law
        compliance. Invalid outputs count as non-consistent.
  \item $\text{both\_correct}(m) = P(\text{normal-correct} \wedge
        \text{transformed obeys the law})$: joint correctness.
  \item $G = A_{\text{normal}} - A_{\text{shuffle}}$ (correct-image
        dependence); $\dG = G_{\text{tuned}} - G_{\text{zero-shot}}$.
\end{itemize}
