No lock files exist; the above is the recorded environment. LoRA hyperparameters
are pinned in the committed adapter configs (`adapter_config.json`: r=8, alpha=16,
dropout 0.05).

## 2. Datasets

| Dataset | Identifier | License | Used for |
|---|---|---|---|
| VSR | `cambridgeltl/vsr_random` (HF) | research use | primary diagnostic benchmark |
| SITE | `franky-veteran/SITE-Bench` (HF) | CC-BY-4.0 | external transfer evaluation (eval-only) |

Splits: VSR train 7,680 / validation 1,097 / test 2,195; all evaluations on test.
SITE: 2,591 image examples (1,368 single-image, 1,223 multi-image) from the
official test configs; media requires a HF read token (not needed for the
committed prediction CSVs).

## 3. Models

- `HuggingFaceTB/SmolVLM2-2.2B-Instruct` (2B conditions)
- `Qwen/Qwen2-VL-7B-Instruct` (7B conditions)
- All LoRA adapters: r=8, alpha=16, dropout 0.05; vision tower frozen; targets per
  condition in the paper's App. B.

## 4. Prompts and decoding

Exact prompt strings (plain VSR prompt, 2B structured prompt, SITE multiple-choice
prompt) are in the supplementary, App. A. Greedy decoding everywhere
(do_sample=False, temperature 0). SITE: max_new_tokens=16 (validated parse-
identical on 125 held-out examples), 392px image cap, official letter parser.

## 5. Seeds / statistical caveats

- Single seed per trained condition; **the single-seed results do not estimate
  training-run variability** (stated in the paper's Limitations and App. D).
- All paired comparisons are exact McNemar tests on the fixed test examples.
- The complete test battery (22 rows: 18 accuracy-valid + 4 agreement-based) and
  Holm adjustments are in App. D.

## 6. What can be reproduced without a GPU (CPU-only)

All of the following reproduce exactly from `wacv2027_code.zip` (see the archive
README for commands):

- Canonical 10-condition VSR table and SITE transfer table
  (`scripts/build_canonical_tables.py`)
- Paired SITE zero-shot vs VSR-LoRA statistics on frozen-ID subsets
  (`scripts/compare_site_zeroshot_lora.py`)
- SITE orientation confound analysis (logistic; OR 0.84, p=0.29)
  (`scripts/site_confound_analysis.py`)
- Consistency verdict patterns incl. expected-under-independence values
  (`scripts/consistency_verdict_table.py`)
- Publication figures and headline-number audit
  (`scripts/make_publication_figures.py`, `scripts/make_paper_figures.py`)
- Clean-label sensitivity table (`scripts/clean_label_orientation.py`)

## 8. Expected outputs / verification

- Re-running the CPU scripts prints the paper's numbers exactly; the audit trail
  `paper/fig/audit_output.txt` (regenerated by `make_paper_figures.py`) maps every
  headline number to its source CSV/JSON.
- The frozen SITE protocol (config hash `28f4cc09887477af`) defines all subsets;
  the secondary orientation subset is the frozen-ID list intersected with the
  2,591 evaluated IDs (n=2,024) — no keyword reconstruction in analysis.

## 9. Fidelity notes

- All prediction CSVs are committed verbatim; none were modified after the fact.
- A run-time metrics JSON for SITE (`zeroshot_image_metrics.json`) records the
  eval run; its secondary-subset figure (n=1,824) differs from the frozen-ID
  recomputation (n=2,024) for a documented reason (an earlier derived analysis
  reconstructed the subset by question-only keyword matching; corrected before
  submission — see supplementary App. E). All other numbers are bit-identical
  across both artifact paths.
