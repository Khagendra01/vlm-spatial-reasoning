FINALIZE BEFORE UPLOAD - READ THIS (after Aug 21 enrollment)
=============================================================

The header you see on main.pdf ("WACV 2027 Submission #*****. Datasets Track.
CONFIDENTIAL REVIEW COPY. DO NOT DISTRIBUTE.") is the OFFICIAL WACV review
header. Every element is correct and required:

  - "Datasets Track" box  -> official track selector (blue box from wacv.sty)
  - "CONFIDENTIAL REVIEW COPY. DO NOT DISTRIBUTE." -> standard review banner,
    present on every WACV review submission; disappears in camera-ready
  - "Anonymous WACV Datasets Track submission" -> double-blind author line

The ONLY thing to change: the paper ID "*****".

When OpenReview assigns your paper number at enrollment (Aug 21):

  1. Run:   python set_paper_id.py <your_paper_id>
     (the script is in the folder above this one, FINAL_WACV2027_SUBMISSION_PAPER2/)
  2. It rebuilds main.pdf + supplementary.pdf with "Submission #<id>"
     and replaces the files in THIS folder (01_UPLOAD_THIS).
  3. Re-verify the SHA-256 hashes (they will change) and note them in
     03_DOCS_CHECKLISTS/WACV2027_SUBMISSION_CHECKLIST.md.
  4. Upload main.pdf on Aug 28, supplementary.pdf + wacv2027_code.zip on Aug 30.
     (the code ZIP does NOT contain the paper ID - it stays unchanged)

The compile toolchain on this machine is MiKTeX (pdflatex), which the
set_paper_id.py script uses. If you cannot run it: tell the ID to your
assistant and they will regenerate the two PDFs and update the manifest.
